# Netflix Content Analysis

An exploratory data analysis and visualization project using Python and Power BI to analyze Netflix's content catalog. The project focuses on understanding content distribution, release trends, countries, genres, ratings, and the differences between Movies and TV Shows.

The dataset was cleaned and prepared using Python before being analyzed and visualized through interactive Power BI dashboards. The analysis aims to identify patterns and insights that could help understand Netflix's content strategy and catalog characteristics.

## Tools & Technologies

- Python
- Pandas
- Power BI
- Power Query

## Key Analysis

- Movie vs TV Show content distribution
- Top countries producing Netflix content
- Most common genres
- Rating distribution
- Geographic distribution of Netflix content
